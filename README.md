# 🐾 Virtual Pet Log

A beginner-friendly full-stack web app to track your pets' moods and daily activities.  
Built with **Python + Flask** on the backend and HTML/CSS/JS on the frontend, with MongoDB as the database.

> Built by Aarush Deshmukh

---

## ✨ Features

- ➕ Add pets with name, type, age and mood
- 📋 View all your pets as cards
- 🦮 Log daily activities (Fed, Walked, Played, Resting)
- 😊 Mood updates automatically based on activity
- 🗑️ Remove pets from your log
- 🍃 All data saved in MongoDB

## 🚀 How to Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/aarushdeshmukh/Virtual-Pet-Log.git
cd virtual-pet-log
```

### 2. Install dependencies
```bash
pip install flask flask-cors pymongo
```

### 3. Make sure MongoDB is running
- Open **MongoDB Compass** and connect to `mongodb://localhost:27017`
- Or run in terminal: `net start MongoDB` (Windows)

### 4. Run the Flask backend
```bash
python app.py
```
You should see:
```
🐾 Virtual Pet Log running at http://localhost:5000
```

### 5. Open the frontend
Double-click `index.html` in your file explorer — or open it in your browser directly.

## 📦 MongoDB Collections

**Database:** `pet_log_db`  
**Collection:** `pets`

Each pet document looks like this:
```json
{
  "_id": "auto-generated by MongoDB",
  "name": "Fluffy",
  "type": "🐱 Cat",
  "age": 2,
  "mood": "Happy 😊",
  "last_activity": "Fed 🍖",
  "created_at": "2025-02-17 14:30"
}
```
